# Dubai_Steel_Section_Designer-MATLAB_GUI
MATLAB GUI for structural steel section design based on Dubai Building Code, AISC 360, and AISC 341. Includes dynamic section geometry, compactness and seismic ductility checks, moment of inertia comparison, section management, reports, file storage, and real-time recalculation.
Features

- Dynamic visualization of steel section geometry
- Automatic calculation of area and moments of inertia
- Compact, noncompact, and slender section checks
- Seismic compactness checks for moderate and special ductility
- Dynamic section report and geometry updates
- Section list management and comparison
- Save and load section databases
- Export individual section reports
- Real-time recalculation using mouse-wheel input

Requirements

- MATLAB R2016b or later
- No additional MATLAB toolboxes required

Usage

Run the following command in MATLAB:

DubaiSteelSectionGUI

Define the section dimensions and material properties. The program automatically updates the geometry, structural properties, and compactness checks.
